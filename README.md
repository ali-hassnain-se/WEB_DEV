# 🌐 Web Engineering & Full-Stack Development

Repository containing structured coursework, laboratory assignments, practical exercises, and modern web application projects.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap / Tailwind CSS
- **Backend:** Node.js, Express.js / PHP
- **Database:** MySQL / MongoDB
- **Tools & Environment:** VS Code, Git, GitHub, Postman / REST Client

---

## 📁 Repository Structure

```bash
├── 01-HTML-CSS-Basics/      # Semantic HTML, Flexbox, Grid, Responsive UI
├── 02-JavaScript-Core/      # DOM Manipulation, ES6+, Async/Await, APIs
├── 03-Backend-Development/  # Server setups, REST APIs, Routing
├── 04-Database-Integration/ # Schemas, CRUD operations, queries
└── Projects/                # End-to-end full-stack web applications
```
